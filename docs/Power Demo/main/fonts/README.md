# 中文字体子集

这里没有复制原固件约 6 MB 的完整中文字库，只保留本页面会实际显示的字形：

- `power_font_16.c`：状态栏数字、日期分隔符、`星期一`至`星期日`。
- `power_font_24.c`：从完整版 `lv_font_montserrat_24` 裁出的温湿度字符。
- `power_digits_48.c`：从完整版 `lv_font_montserrat_48` 裁出的日期数字和占位符。
- `power_lunar_24.c`：从完整版 `zh_flip_lunar_22` 裁出的农历、二十四节气和节日汉字。原文件名虽然写 22，但其源码标注和真实度量均为 24px。

四个字体文件合计约 53 KB，并由 Demo 自带的最小 1-bit 读取器直接使用，不依赖 LVGL。24/48px 拉丁字体已按完整版 RLCD 黑白阈值转换，叠字效果也已预合成，因此运行时无需重复绘制。

这些裁剪后的字形数据已经固化在本目录中，独立编译不需要完整版工程。增加新的界面文字时，必须先离线补充对应字形；否则该文字会显示为空白。
